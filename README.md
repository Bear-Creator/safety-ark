
# SafetyArk

**Dead man's switch** — мобильное приложение для личной безопасности. Периодически проверяет активность пользователя. При отсутствии ответа — автоматически уведомляет доверенных контактов.

---

## Стек

| Слой | Технология |
|---|---|
| Framework | Expo SDK 52 + Expo Router v4 |
| UI / Design | React Native Paper v5 (Material Design 3) |
| Язык | TypeScript |
| Стейт | Zustand + AsyncStorage |
| Сенсоры | expo-sensors (Accelerometer) |
| Платформы | iOS, Android, **Web** (единая кодовая база) |

---

## Запуск

### Требования
- Node.js 18+
- npm или yarn
- (для мобильного) приложение **Expo Go** на телефоне

### Установка

```bash
git clone https://gitlab.com/rigor-erectus/safety-ark.git
cd SafetyArk
npm install
```

### Веб-версия (рекомендуется для быстрой проверки)

```bash
npx expo start --web
```

Откроется браузер на `http://localhost:8081`

### Мобильное приложение

```bash
npx expo start
```

Отсканировать QR-код приложением **Expo Go**

## Реализованный сценарий

**Полный цикл (Сценарий C):** Регистрация → Гайд → Главная → Профиль → Контакты → Параметры → Чек-ап → Тревога → Отмена

### Как проверить:

1. Запустить приложение (`npx expo start --web`)
2. **Войти** — любой email + пароль (мок, валидация только на непустоту)
3. **Регистрация** — 3 шага, данные предзаполнены из мока, нажать "Продолжить" на каждом шаге
4. **Гайд** — прочитать 3 карточки, нажать "Начать настройку"
5. **Главная** — виден таймер с обратным отсчётом и кнопка "✓ Я в норме"
6. **Профиль** → Мои данные — просмотр капсулы, нажать "Показать" у seed-фразы
7. **Профиль** → Доверенные контакты — нажать "+" → заполнить форму → "Сохранить"
8. **Параметры** — выбрать интервал, перейти в "Настройки Check-up"
9. **Чек-ап** (вкладка) — нажать **"🤳 Имитировать тряску"** → таймер сбросится, возврат на главную
10. **Тревога** — нажать "Нужна помощь" на экране Чек-ап → открывается экран тревоги с анимированной отправкой → ввести пароль **`1234`** → тревога отменена
